LAB: File Path Traversal — Traversal Sequences Blocked with Absolute Path Bypass

PortSwigger Web Security Academy — Path Traversal

Objetivo

Este laboratorio contiene una vulnerabilidad de recorrido de ruta en la visualización de imágenes de productos. La aplicación bloquea secuencias transversales pero trata el nombre de archivo proporcionado como si fuera relativo a un directorio de trabajo predeterminado. Para resolver el laboratorio, recupere el contenido del archivo /etc/passwd.
